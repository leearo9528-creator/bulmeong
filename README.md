# 불멍 위젯

**[Bulmeong.exe 내려받기](https://github.com/leearo9528-creator/bulmeong/raw/release/Bulmeong.exe)** (윈도우, 설치 없이 실행)

처음 실행할 때 윈도우 경고가 뜨면 "추가 정보 → 실행"을 누른다.

바탕화면 오른쪽 아래(작업표시줄 위)에 작게 떠 있는 화로대 불멍 위젯. 스테인리스 화로대와 장작, 셰이더로 그린 불꽃만 있다.

## 쓰는 법
- 장작 더미에서 장작을 끌어다 화로대에 놓으면 들어간다. 조금 뒤에 불이 옮겨붙는다
- 참나무는 늦게 붙고 오래 타고, 소나무는 빨리 붙고 불티가 많다
- 불을 클릭하면 부채질(불이 잠깐 세지고 빨리 붙는다). 불이 완전히 꺼졌으면 클릭으로 다시 점화
- 그루터기 위 통나무를 두 번 클릭하면 도끼로 쪼개서 장작 두 개가 더미에 쌓인다
- 장작은 타면서 검게 변하고 줄어들다가 숯이 된다
- 빈 곳을 끌면 창이 움직인다
- 오른쪽 클릭(또는 트레이 아이콘): 화로대 모양, 크기, 소리, 항상 위, 클릭 통과, 자동 실행, 종료

## 개발 실행 (윈도우, Node.js 필요)
```
npm install
npm start
```

## exe 하나로 만들기 (윈도우에서 실행)
```
npm run build
```
`dist/Bulmeong.exe`가 나온다. 설치 없이 실행되는 파일이다. (리눅스에서도 같은 명령으로 만들어진다)

## 구성
- `main.js` 창·메뉴·트레이·설정 저장
- `renderer.js` 화로대·장작·불꽃 셰이더·소리 (외부 이미지나 모델 없이 전부 코드로 그림)
- `vendor/` three.js r128
